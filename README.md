# MDREM-inertial-parameters-estimation-for-FR3-robot
This is a RO2 package that contains the code for the Modified Dynamic Regressor Extension and Mixing (MDREM) algorithm applied to the Franka Research 3 robot to estimate the ten inertial parameters of the robot payload. 

This repository contains the ROS 2 package used for the experimental implementation of the MDREM algorithm on the FR3 robot. For more comprehensive technical information, implementation details, and detailed instructions on running the package, please refer to our main repository here: [Franka Research 3 (FR3): Real-Time Payload Estimation](https://github.com/Netul7/payload-online-estimation-manipulators-/tree/main/2_franka_research_3).
